FREE PUBLISHING OPTION
GitHub Pages can host static HTML for free using a public repository on GitHub Free.
Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages
Create a public repository, upload index.html, then open Settings > Pages and select the publishing source.
The free address will usually be https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
A custom domain is optional and usually costs extra.
